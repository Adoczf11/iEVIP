# R code for iEVIP single-vesicle profiling analysis

This folder contains R scripts used for data visualization, multivariate analysis, batch-effect correction, and classification in the study:

iEVIP: A Dual-inspired Intelligent Platform for Smart Response Extracellular Vesicle Isolation and Single-Vesicle Profiling

The scripts support the profiling-related computational analyses, including heatmap visualization, principal component analysis (PCA), partial least squares discriminant analysis (PLS-DA), linear discriminant analysis (LDA), t-distributed stochastic neighbor embedding (t-SNE), batch-effect correction, and machine-learning-based classification.

## Folder structure

In the Code Ocean capsule, the profiling scripts should be placed under:
/code/code_profiling
Input data should be placed under:
/data
Output files generated by the scripts should be saved to:
/results
A recommended structure is:
/code
└── code_profiling
    ├── Heatmap.R
    ├── PCA.R
    ├── PLS-DA.R
    ├── LDA_visualization.R
    ├── tSNE.R
    ├── ComBat_batch_correction.R
    └── RF+NNET+LDA+Confusion_matrix+ROC+PR.R

## Input data

The following datasets are used for the profiling-related analyses.

### cell_EV.csv

This file contains data derived from cell-based extracellular vesicle experiments. Each row corresponds to an independent cell sample, and columns represent measured features used for downstream multivariate analysis and classification.

This dataset was used for heatmap visualization, PCA, PLS-DA, LDA, and combined classification analyses.

### Batch1_EV.csv and Batch2_EV.csv

These files contain extracellular vesicle data from two independent batches of clinical samples. They were used for batch-specific visualization, comparative analysis, and classification-related evaluation.

### features.csv

This file contains the combined feature data from two clinical sample batches. It was used for batch-effect correction and evaluation of inter-batch variation.

## Description of individual scripts

### Heatmap.R

This script performs data normalization where applicable and generates heatmaps to visualize global feature patterns across samples. It is used to explore sample similarity, clustering patterns, and group-specific trends.

### PCA.R

This script conducts principal component analysis (PCA) as an unsupervised dimensionality reduction method. PCA is used to visualize the overall structure of the dataset, identify dominant sources of variance, and assess sample distribution patterns.

### PLS-DA.R

This script performs partial least squares discriminant analysis (PLS-DA) as a supervised multivariate classification approach. It is used to evaluate group separation and identify features contributing to class discrimination.

### LDA_visualization.R

This script applies linear discriminant analysis (LDA) as a linear and interpretable classification method. LDA is used for visualization of class separation and serves as a baseline classifier for comparison with other models.

### tSNE.R

This script performs t-distributed stochastic neighbor embedding (t-SNE) as a nonlinear dimensionality reduction approach. It is used to visualize sample clustering patterns and group separation in a low-dimensional space.

### ComBat_batch_correction.R

This script performs batch-effect correction for features shared across different sample batches. It is used to reduce nonbiological inter-batch variation, visualize the correction performance by PCA, and generate batch-corrected data for subsequent classification analysis.

### RF+NNET+LDA+Confusion_matrix+ROC+PR.R

This script implements and compares multiple classification models, including Random Forest (RF), Neural Network (NNET), and Linear Discriminant Analysis (LDA). It is used to evaluate classification performance under different modeling assumptions and to assess model robustness.

The script also generates confusion matrices, receiver operating characteristic (ROC) curves, and precision-recall (PR) curves where applicable.

## Running the scripts

In the Code Ocean capsule, open the terminal and enter the profiling code folder:

cd /code/code_profiling

Each script can be run individually in R. For example:

source("Heatmap.R")
source("PCA.R")
source("PLS-DA.R")
source("LDA_visualization.R")
source("tSNE.R")
source("ComBat_batch_correction.R")
source("RF+NNET+LDA+Confusion_matrix+ROC+PR.R")


Before running the scripts, please ensure that the required input data files are available under the `/data` directory and that output paths are set to `/results` or its subfolders.

## Output files

## Reproducibility

All scripts were executed using R version 4.3.0. Where applicable, random seeds were set within the scripts to ensure reproducibility.

The output figures and tables generated by these scripts correspond to the profiling-related analyses presented in the manuscript.

## Data availability

The source data used to generate each figure are provided in files named according to the corresponding analyses or figures.

The `Batch1_EV.csv` and `Batch2_EV.csv` datasets contain extracellular vesicle data from two independent batches of clinical samples.

The `features.csv` dataset contains the combined data from these two batches and was used for batch-effect correction.
